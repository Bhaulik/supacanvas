# Supacanvas — Chrome Extension

Vertical right-side panel that shows your supacanvas gallery from any browser tab. Click the toolbar icon to dock it on the right; right-click any selection on a webpage to save it as a new canvas.

> Local-only, no auth, no telemetry. Talks to `http://localhost:7777` (the supacanvas server you already run via `supacanvas serve`).

## Install (developer / unpacked)

```sh
cd extension
bun install
bun run build
```

Then in Chrome:

1. Open `chrome://extensions`
2. Toggle **Developer mode** (top-right)
3. Click **Load unpacked**
4. Select `extension/.output/chrome-mv3/`

The extension icon appears in the toolbar. **Click it to open the side panel on the right edge of the window** (Chrome 116+; older Chrome: open the side panel manually via Chrome's UI and pick Supacanvas).

The side panel auto-refreshes every 30 seconds, so canvases your AI tools create show up without a reload. Click the ↻ icon next to the title to refresh on demand.

## Use

### Browse / search / open
- Click any card to open that canvas at `localhost:7777/c/<id>` in a new tab — the side panel stays docked.
- Type in the search box — debounced search hits `/api/canvases?search=…`.
- Click a folder chip to filter; click **All** to clear.
- Click the ↻ refresh icon (top-right of masthead) for an immediate reload.

### Save a page or selection
- Highlight any text on a webpage → right-click → **Save to Supacanvas**.
- Or right-click empty area → **Save to Supacanvas** to save the whole page body.
- A notification appears with the canvas title. Click it to open the new canvas.

Captured canvases land in the `captures/` folder with `source: chrome-extension:supacanvas`. Inline event handlers and `<script>` tags are stripped on capture; everything renders inside supacanvas's sandboxed iframe in the viewer.

### Open the gallery
- Footer **Open Gallery →** opens `localhost:7777/` (or `?folder=<active-filter>` if a folder chip is selected).

## Develop

```sh
bun run dev          # WXT auto-reloads as you edit
bun run compile      # tsc --noEmit (typecheck only)
bun run build        # production build → .output/chrome-mv3
bun run zip          # also bundles a zip for distribution
```

`bun run dev` opens a fresh Chrome profile with the extension auto-loaded and HMR active. Edits to popup/sidepanel reload instantly; background-worker changes trigger a service-worker reload.

## Architecture: the CORS workaround

The supacanvas server (Hono on Node) does not set `Access-Control-Allow-Origin`. A direct `fetch()` from the side panel context fails. **Every API call routes through the background service worker**, which is CORS-exempt because `host_permissions` declares `http://localhost:7777/*`.

```
[sidepanel / content script]
     │  chrome.runtime.sendMessage({ type: "api", method, path, body })
     ▼
[background.ts]
     │  fetch("http://localhost:7777" + path, ...)
     ▼
[supacanvas Hono server]
```

Image `<img src="…/screenshot.png">` requests are NOT subject to this — thumbnails load directly in the panel.

### Why side panel only (no popup)

Popups dismiss the moment you click outside, so any click on a canvas tears the popup down. The side panel docks persistently on the right — you can browse, click, and keep working without losing the gallery. The action button is wired to open the panel directly via `chrome.sidePanel.setPanelBehavior({ openPanelOnActionClick: true })`.

## Permissions justification

| Permission | Why |
|---|---|
| `sidePanel` | Render the persistent side panel UI |
| `contextMenus` | Add "Save to Supacanvas" right-click entry |
| `notifications` | Confirm a successful capture and link to the new canvas |
| `activeTab` + `scripting` | Send capture messages to the active tab's content script |
| `storage` | (reserved for future settings) |
| `host_permissions: http://localhost:7777/*` | Bypass CORS for local API calls |

No remote hosts, no analytics, no auth, no third-party scripts.

## Customizing

### Server runs on a different port?
Edit two places, then rebuild:
- `wxt.config.ts` → `host_permissions: ["http://localhost:<port>/*"]`
- `components/api.ts` → `SERVER_URL = "http://localhost:<port>"`
- `entrypoints/background.ts` → `SERVER_URL` constant near top

### Replace the icon
Drop your own PNGs at `public/icon/{16,48,128}.png` and rebuild. Or edit `scripts/make-icons.ts` and run `bun run scripts/make-icons.ts`.

4. Type in search → list filters live.
5. Click a card → new tab opens at `localhost:7777/c/<id>`.
6. Open the side panel → mirrors the popup with vertical card layout.
7. Highlight text on any webpage → right-click → **Save to Supacanvas** → notification appears → click → new canvas in the `captures/` folder.
